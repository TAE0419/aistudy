React AI Study | 현재 홈페이지 안내 자료
파일 버전: 4.0
목적: 향후 목표가 아닌 현재 구현된 화면과 기능을 기준으로 이용 방법을 안내합니다.

[00. 챗봇 공통 답변 원칙]
- 현재 기능: React AI 학습(개념 설명, 문제 만들기, 정답 보기, 힌트 받기), 도시별 현재 날씨 검색, 페이지 가이드 챗봇.
- 상단 메뉴: '홈'(/), 'AI 학습'(/study), '날씨 API'(/weather).
- 로그인, 로그아웃, 회원가입, 비밀번호 재설정, 카카오·네이버 등 소셜 로그인은 없습니다. 계정 없이 이용합니다. 가입 화면이나 로그인 버튼으로 안내하지 않습니다.
- 사용자 간 실시간 채팅, 채팅방, WebSocket 채팅은 없습니다. 페이지 가이드의 AI 대화창과 사용자 간 채팅을 혼동하지 않습니다.
- Express 서버, MySQL 데이터베이스, 계정별 학습 기록 저장·조회 기능은 없습니다.
- 주제 선택 목록, 정해진 강좌 목록, 답안 제출, 자동 채점, 점수·학습 진도 관리 기능은 없습니다. 주제는 질문란에 직접 입력합니다.
- 학습 답변, 현재 문제, 정답, 힌트는 학습 페이지의 임시 상태이며 새로고침하거나 다른 페이지로 이동하면 유지되지 않습니다. 가이드 대화도 영구 저장하지 않으며 새로고침하면 초기화됩니다. 가이드 창을 닫았다 열거나 상단 메뉴로 페이지를 이동하는 동안에는 공통 레이아웃의 가이드 대화가 유지됩니다.
- 자료에 없는 기능, 메뉴, 가격, 정책, 출시 일정은 추측하지 않습니다. 확인되지 않은 내용은 확인되지 않았다고 답합니다.
- 대소문자, 띄어쓰기와 퀴즈/문제 같은 유사 표현을 고려하되 실제 버튼 이름으로 안내합니다.
- 짧고 친절한 한국어로 답하고 이용 방법은 화면의 버튼 이름과 순서에 맞게 설명합니다.
- 비밀번호, API 키, 액세스 토큰 등 비밀 정보를 요청하지 않습니다.

[01. 홈페이지 소개와 이동]
대표 명칭: 홈페이지 소개
관련 표현: 사이트 소개, 이 사이트, 어떤 홈페이지, 무슨 사이트, 주요 기능, 무엇을 할 수 있어, 사용법, 안내, 시작하기, 메뉴, 홈
기능 설명: React 중심의 AI 학습 사이트입니다. 현재 날씨 검색과 페이지 가이드도 제공합니다.
이용 방법: 상단 'AI 학습' 또는 홈의 '학습 바로가기'로 학습을 시작합니다. 날씨는 상단 '날씨 API' 또는 홈의 '날씨 확인 바로가기'로 이동합니다.
Q. 어떤 기능이 있어?
완성형 답변: React 개념 설명, 문제 만들기, 정답 보기, 힌트 받기, 도시별 현재 날씨 검색, 페이지 가이드 챗봇이 있습니다. 회원가입 없이 이용할 수 있어요.

[02. React 학습과 개념 설명]
대표 명칭: 개념 설명
관련 표현: 리액트, react, 공부, 학습, 강좌, 수업, 개념설명, 설명, 알려줘, 예제, 코드 설명, useState
기능 설명: React 및 관련 JavaScript, TypeScript, Next.js 질문에 대해 AI 설명을 제공합니다. 별도 강좌나 주제 선택 목록은 없습니다.
이용 방법: 'AI 학습'(/study)에서 '개념 설명'을 선택하고 질문란에 내용을 입력한 뒤 '질문하기'를 누릅니다.
Q. useState가 뭔지 알고 싶어요.
완성형 답변: 'AI 학습'에서 '개념 설명'을 선택하고 질문란에 'useState를 쉽게 설명해줘'를 입력한 뒤 '질문하기'를 누르세요.

[03. 문제 만들기와 정답 확인]
대표 명칭: 문제 만들기
관련 표현: AI퀴즈, ai quiz, 퀴즈, 문제, 문제풀기, 문제 풀기, 문제 출제, 연습문제, 테스트, 정답, 답안, 답변 보기, 정답 보기, 정답 숨기기, 해설, 채점, 점수
기능 설명: 입력한 주제로 문제 1개를 생성합니다. 처음에는 문제만 표시하고 힌트와 정답은 표시하지 않습니다. 정답과 해설은 '정답 보기'로 확인합니다. 답안 제출과 자동 채점은 없습니다.
이용 방법: 'AI 학습'에서 '문제 만들기'를 선택하고 주제를 입력한 뒤 '질문하기'를 누릅니다. 문제 아래 '정답 보기'로 정답과 해설을 확인하고 '정답 숨기기'로 다시 숨깁니다.
Q. AI 퀴즈는 어떻게 사용하나요?
완성형 답변: 'AI 학습'에서 '문제 만들기'를 선택하고 원하는 주제를 입력한 뒤 '질문하기'를 누르세요. 문제를 풀어보고 아래의 '정답 보기'로 정답을 확인하세요.
Q. 새 문제를 만들면 이전 정답이 보이나요?
완성형 답변: 새 문제를 만들면 이전 힌트와 정답 공개 상태가 초기화됩니다. 새 정답은 다시 '정답 보기'를 눌러 확인하세요.

[04. 힌트 받기]
대표 명칭: 힌트 받기
관련 표현: 힌트, hint, 도움말, 단서, 실마리, 풀이 도움, 모르겠어, 막혔어, 최근 문제
기능 설명: 가장 최근에 생성한 문제를 서버에 전달해 AI에게 힌트를 요청하고 문제 아래에 추가합니다. 문제 생성 시 힌트를 함께 표시하지 않습니다. 힌트는 정답을 직접 공개하지 않습니다.
이용 방법: 먼저 '문제 만들기'에서 주제를 입력하고 '질문하기'로 문제를 생성합니다. 이후 '힌트 받기'를 클릭하면 별도 질문 입력 없이 현재 문제의 힌트를 요청합니다. 힌트 모드의 아래쪽 '힌트 받기' 버튼으로도 다시 요청할 수 있습니다.
Q. 힌트는 어디서 보나요?
완성형 답변: 문제를 먼저 만든 뒤 '힌트 받기'를 클릭하세요. 현재 문제 아래에 힌트가 추가됩니다. 새 문제를 만들면 이전 힌트는 초기화됩니다.

[05. 회원가입과 로그인 미제공]
대표 명칭: 회원가입과 로그인
관련 표현: 가입, 회원가입, 회원정보, 계정, 아이디, sign up, signup, 로그인, 로그임, login, log in, 로그아웃, 비밀번호, 인증, 카카오, kakao, 네이버, naver, 소셜 로그인, 간편 로그인
기능 설명: 현재 회원가입, 로그인, 로그아웃, 비밀번호 재설정, 소셜 로그인 기능이나 회원정보를 수집하는 가입 화면은 없습니다.
Q. 회원가입은 어떻게 해요?
완성형 답변: 현재 회원가입과 로그인 기능은 없습니다. 계정 없이 'AI 학습'과 '날씨 API'를 이용할 수 있습니다.
Q. 카카오나 네이버로 로그인할 수 있나요?
완성형 답변: 현재 소셜 로그인은 제공하지 않습니다. 로그인 없이 사이트 기능을 이용하세요.

[06. 사용자 간 채팅 미제공]
대표 명칭: 사용자 간 채팅
관련 표현: 채팅, chat, 대화방, 실시간 대화, 다른 사람, 웹소켓, websocket, 채팅방, 메시지
기능 설명: 다른 사용자와 대화하는 실시간 채팅 기능은 없습니다. 오른쪽 아래 대화창은 홈페이지 사용법을 알려주는 AI 가이드입니다.
Q. 다른 사람과 대화하려면 어떻게 해요?
완성형 답변: 현재 사용자 간 채팅이나 대화방은 없습니다. 오른쪽 아래 챗봇은 사이트 사용법을 안내하는 AI 가이드입니다.

[07. 현재 날씨 검색]
대표 명칭: 날씨 검색
관련 표현: 날씨, weather, 기온, 온도, 기상 정보, 오늘 날씨, 날씨 API, 도시, Seoul, 서울, 예보, 위치
기능 설명: 입력한 도시의 현재 날씨를 OpenWeather API로 검색하고 도시 이름, 날씨 설명, 섭씨 기온을 표시합니다. 초기 입력값은 Seoul이며 검색 버튼을 눌러야 결과를 가져옵니다. 자동 위치 감지나 주간 예보 기능은 없습니다.
이용 방법: 상단 '날씨 API'(/weather)에서 도시 이름(예: Seoul)을 입력하고 '날씨 검색'을 누릅니다.
Q. 날씨는 어디서 확인하나요?
완성형 답변: 상단 '날씨 API'에서 도시 이름을 입력하고 '날씨 검색'을 누르세요. 해당 도시의 현재 날씨와 기온을 확인할 수 있습니다.
Q. 날씨가 안 나와요.
완성형 답변: 도시 이름을 확인하고 '날씨 검색'을 다시 눌러 보세요. 계속 실패하면 화면의 오류를 확인해 주세요. 외부 날씨 API나 서버 설정에 문제가 있을 수 있습니다.

[08. 페이지 가이드 챗봇]
대표 명칭: 페이지 가이드
관련 표현: 가이드, 챗봇, chatbot, 상담, 사용법 질문, 홈페이지 도움말, 안내 봇, 오른쪽 아래 버튼, 말풍선 버튼, 대화 기억
기능 설명: 모든 페이지 오른쪽 아래의 AI 사용 안내 도우미입니다. 질문을 입력하고 전송 버튼 또는 Enter로 전송하며 닫기 버튼으로 닫습니다. 현재 질문만 서버에 전달하며 이전 대화 맥락은 서버에 전달하지 않습니다.
Q. 이 챗봇은 무엇을 해 주나요?
완성형 답변: React AI 학습, 문제·정답·힌트 확인, 날씨 검색 등 현재 사이트의 이용 방법을 안내합니다. React 개념을 자세히 배우려면 'AI 학습'의 '개념 설명'을 이용하세요.

[09. 학습 기록과 저장 범위]
대표 명칭: 학습 기록
관련 표현: 기록, 저장, 이전 퀴즈, 지난 문제, 힌트 기록, 학습 내역, 영구 저장, 새로고침, 데이터베이스, MySQL, Express, 진도
기능 설명: 답변과 가장 최근 문제·정답·힌트를 현재 페이지의 임시 상태로 관리합니다. 영구 저장, 이전 학습 이력 조회, 계정별 저장, 진도 관리는 없습니다. 새로고침 또는 페이지 이동 시 초기화됩니다.
Q. 지난번에 푼 문제를 다시 볼 수 있나요?
완성형 답변: 학습 기록을 저장하거나 지난 문제 목록을 조회하는 기능은 없습니다. 현재 문제는 페이지를 새로고침하거나 이동하면 사라집니다.

[10. 학습자료 검색과 안내 범위]
대표 명칭: 학습자료 검색
관련 표현: RAG, 검색 기반 AI, 문서 기반 답변, 자료 참고, AI 학습자료, 지원 기능, 차트, chart, 가격, 예정, 출시, 업로드
기능 설명: AI 학습과 가이드는 서버에서 준비된 텍스트 자료를 키워드로 검색해 AI 답변에 참고합니다. 별도 RAG 버튼이나 문서 업로드 기능은 없습니다. /chart 경로는 빈 화면이며 이용 가능한 차트 기능이 아닙니다. 자료에 없는 기능이나 출시 일정은 확인할 수 없습니다.
Q. RAG 버튼을 따로 눌러야 하나요?
완성형 답변: 아니요. 학습 질문을 보내면 서버에서 관련 학습자료를 자동으로 검색해 답변에 참고합니다.
Q. 홈페이지에 없는 기능이 어디 있나요?
완성형 답변: 현재 제공되는 것으로 확인되지 않은 기능은 위치나 이용 방법을 안내할 수 없습니다. React AI 학습, 날씨 검색, 페이지 가이드를 이용할 수 있습니다.
